## 🔬 Research Focus

My research bridges physical superconducting processor hardware and quantum information theory across two primary pillars:

1. **Quantum Hardware Security, Pulse Control & Characterization**
   - Multi-tenant superconducting processor isolation and crosstalk attack modeling.
   - Pulse-to-circuit mapping and Hamiltonian simulations using Qiskit Pulse and QuTiP.
   - Pauli-transfer-matrix (PTM) drift separation, quantum edge detection, and randomized benchmarking.
   - *Publications: IEEE HOST '27, ACM CCS QSec '25, IEEE QCE '25.*

2. **Quantum Communication, Correlations & Error Correction**
   - Correlation-guided adaptive purification and superdense coding over distributed networks.
   - High-fidelity state teleportation over noisy channels using optimal POVM measurements.
   - Surface-code ensemble decoders (RESCUED) and hybrid quantum key distribution (QKD).
   - *Publications: AVS Quantum Science '25, IEEE QCE '25, Heliyon '23.*

## 🌐 Site Architecture & Features

The website is engineered with pure vanilla web technologies (HTML5, modern CSS3, vanilla JavaScript) with zero heavy framework overhead, ensuring sub-second load times and full static hosting on GitHub Pages.

### 1. Main Portfolio (`index.html`)
- **Scholarly Profile**: Compact academic bio, research appointments, education history, and downloadable Curriculum Vitae.
- **Dual Research Pillars**: Interactive cards breaking down primary focus areas, methodology, and key accepted papers.
- **Scholarly Impact Strip**: Live citation metrics (71 citations, h-index 4, i10-index 3) and academic honors including the 2026 Quantum Rising Star Award (Rice University / QS3).
- **Searchable Publication Repository**: Real-time filtering (Selected, First-Author, Hardware Security, Communication & QEC, Co-Supervised), live search query, modal abstracts, one-click BibTeX downloads, and citation copying.
- **Academic Ecosystem**: Tracked updates timeline, invited talks, service/reviewing duties, teaching assistantships, and co-supervised Ph.D. mentee roster.
- **LSU Academic Theme**: Custom Royal Purple (`#461D7C`) and Gold (`#D4AF37`) palette with persistent dark/light theme switching.

### 2. Interactive QSVT Simulator (`QSVT.html`)
- Educational laboratory and browser simulator for **Quantum Singular Value Transformation (QSVT)**.
- Visual breakdown of the 4-stage pipeline: Projector-Controlled Phase Modulation, Block Encoding Unitary $\mathcal{U}$, Chebyshev polynomial transformation $P(A)$, and projective measurement.
- Interactive controls demonstrating cosine-sine block encoding and polynomial synthesis.

### 3. Research Blog & Epistemology Essays (`blog.html`)
- **Quantum Research Notes**: Technical walkthroughs covering QSVT algorithms, multi-qubit teleportation over GHZ states, crosstalk drift signatures, and topological surface-code decoders.
- **Philosophical Inquiries**: Long-form essays covering formal epistemology (The Agrippan Trilemma), Gödel's Ontological Argument, Schopenhauer and free will (Beyond Sisyphus), and contemporary sociology.

### 4. Quantum-Shuffled Memeology & Outreach (`passions.html`)
- **42 Educational Memes**: High-resolution memes across Physics, Quantum Information, Mathematics, and Philosophy with complete mathematical derivations and LaTeX explanations.
- **Live ANU Quantum Random Seed**: Shuffled upon every page load using true quantum vacuum fluctuations generated by the Australian National University (ANU) Quantum Optics laboratory via a dedicated Cloudflare Worker proxy.
- **Pedagogy & Recreation**: Self-recorded video lecture playlists (Complex Analysis, CHSH Nonlocal Games), Substack essays, and recreational chess links (YouTube Chess content [@SchrodingersDankKnight](https://www.youtube.com/@SchrodingersDankKnight/shorts) and Chess.com [@decohered_imam](https://www.chess.com/member/decohered_imam)).

## 🛠️ Data-Driven Architecture

All portfolio content is decoupled from layout and managed centrally through structured JSON/JS data:

```
├── index.html                   # Main academic homepage
├── QSVT.html                    # Interactive QSVT simulator
├── blog.html                    # Blog and philosophical essays
├── passions.html                # Quantum-shuffled meme gallery and outreach
├── portfolio_studio.py          # Zero-dependency local GUI / CMS manager
├── data/
│   ├── portfolio_data.json      # Single source of truth for publications, bio, pillars
│   └── portfolio_data.js        # Offline fallback bundle (window.PORTFOLIO_DATA)
├── images/                      # Research diagrams, profile photos, and meme assets
├── assets/                      # PDFs (CV), fonts, and stylesheets
└── qrng-worker/                 # Cloudflare Worker for ANU Quantum Random Number Generator
    ├── wrangler.toml
    └── src/index.ts
```

## 🖥️ Local Management with Portfolio Studio

To easily update publications, news, metrics, and essays without manually editing JSON files, this repository includes a standalone local management studio:

```bash
# Run Portfolio Studio (macOS / Linux / Windows)
python3 portfolio_studio.py
```

Or on macOS, double-click:
```bash
./Launch\ Portfolio\ Studio.command
```

This launches a lightweight local HTTP server at `http://localhost:8000` with an intuitive web GUI to edit entries, add papers, update citation counts, and write directly to `data/portfolio_data.json` and `data/portfolio_data.js`.

## 📈 Automated Daily Citation Sync (`.github/workflows/update_citations.yml`)

The portfolio automatically stays in sync with your public Google Scholar profile:

- **Schedule**: Runs daily at 06:00 UTC via GitHub Actions (or on-demand via manual trigger).
- **Execution Script**: [`scripts/update_scholar_citations.py`](file:///Users/syedshubha/.gemini/antigravity/scratch/syedshubha.github.io/scripts/update_scholar_citations.py).
- **Automated Sync**: When citations, h-index, or i10-index change, it automatically commits and pushes updates to `data/portfolio_data.json`, `data/portfolio_data.js`, `index.html`, and `README.md`.
- **Fail-Safe**: If Google temporarily rate-limits or serves a CAPTCHA to cloud runner IPs, the run exits gracefully without failing, retrying automatically on the next cycle.

## 🎲 Quantum Seed Worker (`qrng-worker/`)

The meme gallery is dynamically shuffled using real quantum vacuum fluctuations:

- **Provider**: Australian National University (ANU) Quantum Optics Lab QRNG API.
- **Infrastructure**: Cloudflare Worker with Cloudflare KV storage caching.
- **Endpoint**: `https://qrng-seed.small-surf-f6bc.workers.dev/`
- **Fallback**: Fast 32-bit PRNG (`mulberry32`) Fisher-Yates shuffle seeded with system time and client IP when offline or rate-limited.

To deploy or modify the worker:
```bash
cd qrng-worker
npm install
npx wrangler secret put ANU_API_KEY
npx wrangler deploy
```
